PlayTracker - Google Play listing copy
======================================
Working title: PlayTracker Stats
Package name: org.playtracker.app
Default language: English (United States)
App category: Sports (Lifestyle secondary if available)

How to use
----------
Create the Play Console app, then paste each file into the matching
Store listing field.

Files
-----
short-description.txt  - Short description (80)
full-description.txt   - Full description (4000)
urls-and-metadata.txt  - Privacy URL, support email, website, etc.
release-notes.txt      - Production release notes for 1.3.1

Graphics
--------
512 icon:            static/img/promo/play-icon-512.png
1024x500 feature:    static/img/promo/play-feature-graphic.png
Phone screenshots:   refresh for themes (you are handling capture)

Version (align with mobile/app.json)
------------------------------------
1.3.1 (versionCode 18)

Release notes: release-notes.txt

Android build
-------------
EAS production profile builds an AAB from the local mobile/ tree:

  cd mobile && eas build --platform android --profile production

Upload the AAB in Play Console when EAS finishes. Screenshots and listing
copy can land after the binary.

Note: googleAndroidClientId / google-services.json may still be incomplete
for Google Sign-In on Android. Email + Apple (iOS) paths are primary for review.
Data safety form remains a separate Play Console step.
