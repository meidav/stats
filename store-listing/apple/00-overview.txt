How to use
----------
Open each .txt file in this folder and paste into the matching
App Store Connect field on iOS App Version 1.3.3 (Prepare for Submission).

Files
-----
promotional-text.txt   - Promotional Text (170)
description.txt        - Description (4000)
keywords.txt           - Keywords (100)
urls-and-metadata.txt  - Support URL, Marketing URL, Copyright, Version
whats-new.txt          - What's New (for version 1.3.3)
1.3.3/                 - Version-specific ASC paste pack for 1.3.3
1.3.2/                 - Previous pack
1.3.1/                 - Previous pack
1.3.0/                 - Previous pack
1.2.0/                 - Previous release pack
1.1.4/                 - Earlier launch copy
review-notes.txt       - App Review Information notes

Play 512 icon:   static/img/promo/play-icon-512.png
Feature graphic: static/img/promo/play-feature-graphic.png

After a rebrand, re-upload the 1024 icon + feature graphic in ASC / Play Console.
Screenshots: refresh for themes + new chrome (you are handling capture).

Builds (1.3.3, build 20)
------------------------
From mobile/, regenerate the Xcode project before archiving:

  npm run prebuild:ios
  # Quit Xcode first, then open ios/PlayTracker.xcworkspace, Archive, upload

Android AAB via EAS:

  eas build --platform android --profile production

Version lives in app.json (version, ios.buildNumber, android.versionCode).
Bump buildNumber + versionCode for each store upload; bump version for releases.
EAS project: extra.eas.projectId in app.json (owner: stacktracker).
