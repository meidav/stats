PlayTracker Stats - App Store Connect listing copy
==================================================
App Store display name: PlayTracker Stats
Bundle ID: org.playtracker.app
SKU: playtracker-ios
Primary language: English (U.S.)
Primary category: Sports
Secondary category: Lifestyle
Age rating: 4+

How to use
----------
Open each .txt file in this folder and paste into the matching
App Store Connect field on iOS App Version 1.1.4 (Prepare for Submission).

Files
-----
promotional-text.txt   - Promotional Text (170)
description.txt        - Description (4000)
keywords.txt           - Keywords (100)
urls-and-metadata.txt  - Support URL, Marketing URL, Copyright, Version
whats-new.txt          - What's New (for version 1.1.4)
review-notes.txt       - App Review Information notes (optional but helpful)

Assets
------
App icon (1024): mobile/assets/PlayTracker-iOS-App-Icon-1024.png
  (also copied to static/img/promo/ for easy ASC upload if needed)
Splash:          mobile/assets/splash.png

Apple pulls the App Store icon from the uploaded build's AppIcon
asset (generated by Expo/EAS from the icon above). You do not
normally upload a separate icon file in ASC for the listing icon.

Screenshots: drop into static/img/promo/ when ready, then upload
to ASC for the 6.7" (and optional second size) slots.

Builds (1.1.4, build 14)
------------------------
From mobile/:

  npm run prebuild:ios          # Xcode project in ios/ (gitignored)
  # Then Archive in Xcode (or xcodebuild) and Distribute via Organizer

  npm run prebuild:android      # optional; EAS can prebuild on server
  eas build --platform android --profile production

Version lives in app.json (version, ios.buildNumber, android.versionCode).
Bump buildNumber + versionCode for each store upload; bump version for releases.
EAS project: extra.eas.projectId in app.json (owner: stacktracker).
